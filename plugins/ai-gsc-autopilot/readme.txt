اتصال مستقیم به Google Search Console، دریافت خودکار خطاهای ایندکس و مشکلات سئو، تحلیل هوشمند و اجرای مستقیم اصلاحات روی سایت.

== Description ==
افزونه **اتوپایلوت هوشمند سرچ کنسول (AI Search Console Autopilot)** مستقیماً به API رسمی Google Search Console متصل می‌شود و با همکاری افزونه **فرمانده هوشمند سایت (AI Site Commander)** یک چرخه کامل و خودکار تشخیص، تحلیل و رفع خطا را اجرا می‌کند:

* اتصال بدون دردسر با کلید JSON اکانت سرویس گوگل (Service Account) یا OAuth 2.0
* دریافت داده‌های Search Analytics (کلیک، ایمپرشن، CTR، جایگاه و مقایسه ۲۸ روزه) و URL Inspection زنده
* شناسایی خودکار خطاهای ۴۰۴، تگ‌های noindex، مغایرت Canonical، افت ترافیک، CTR پایین، کنیبالیزیشن و خطاهای اسکیما
* تحلیل ریشه‌ای با هوش مصنوعی (OpenAI / Claude / Gemini / OpenRouter یا ایجنت خارجی MCP)
* اجرای یک‌کلیکی یا زمان‌بندی‌شده (Autopilot) اصلاحات روی سایت همراه با Snapshot قابل بازگشت
