# wp-plugin — افزونهٔ وردپرس «هماهنگ‌ساز افزونه‌ها»

این پوشه یک افزونهٔ کامل و نصب‌شدنی وردپرس است که تنظیمات همهٔ افزونه‌های فعال سایت را
تحلیل، هماهنگ و (در حالت خودکار) تنظیم می‌کند.

| مسیر | توضیح |
|---|---|
| `plugin-harmony/` | سورس افزونه |
| `plugin-harmony.zip` | بستهٔ آمادهٔ نصب (خروجی `build.sh`) |
| `build.sh` | ساخت دوبارهٔ فایل زیپ |

## نصب سریع

```bash
bash wp-plugin/build.sh
# سپس در وردپرس: افزونه‌ها ← افزودن ← بارگذاری افزونه ← plugin-harmony.zip
```

یا با WP-CLI:

```bash
wp plugin install wp-plugin/plugin-harmony.zip --activate
wp harmony scan          # گزارش وضعیت
wp harmony preview       # پیشنهادها بدون نوشتن
wp harmony apply         # اعمال (با نسخهٔ پشتیبان و قابلیت بازگردانی)
```

## چه کاری انجام می‌دهد

- پروفایل سایت را می‌سازد (وردپرس، PHP، زبان، HTTPS، پیوند یکتا، کش شیء، سرور، ووکامرس، حجم محتوا).
- افزونه‌های فعال را می‌شناسد (با نام فایل و همچنین کلاس/ثابت، تا تغییر نام پوشه تشخیص را نشکند).
- نقشهٔ قابلیت‌ها را می‌سازد و برای هر کار یک افزونهٔ مرجع انتخاب می‌کند.
- تضادها را گزارش می‌دهد (دو سئو، دو کش، دو فایروال، دو کد آمار، دو صفحه‌ساز، دو افزونهٔ چندزبانه).
- تنظیمات را با نسخهٔ پشتیبان قبلی می‌نویسد، بعد از نوشتن مقدار واقعی را تأیید می‌کند و یک‌کلیک بازمی‌گرداند.
- با فعال‌شدن هر افزونهٔ جدید، در درخواست بعدی مدیر کل سایت را دوباره بررسی و افزونهٔ تازه را هماهنگ می‌کند.
- اسکن روزانه، ناهماهنگی‌های پس از به‌روزرسانی افزونه‌ها را ترمیم می‌کند.

جزئیات کامل، مدل ایمنی و محدودیت‌ها در [`plugin-harmony/README.md`](plugin-harmony/README.md) آمده است.

## تست

منطق افزونه با یک وردپرس شبیه‌سازی‌شده روی PHP 8.3 اجرا و با ۶۲ سنجه بررسی شده است:
ساخت نقشهٔ تغییرات، اعمال، تأیید مقدار نوشته‌شده، بازگردانی، تشخیص تضاد، حالت‌های
«پیشنهاد/کم‌خطر/کامل/غیرفعال»، قواعد سفارشی، گزینه‌های محافظت‌شده، رندر همهٔ تب‌های مدیریت،
چرخهٔ فعال‌سازی افزونهٔ جدید و اسکن روزانه.
